# Financial Intelligence Agent Specification

## Objective
Build an AI-powered financial intelligence platform capable of retrieving financial-market information and providing data-driven portfolio analysis and scenario simulation.

## Core capabilities
- Market intelligence
- Portfolio management
- Portfolio simulation
- Risk analysis
- Fundamental analysis
- Macroeconomic context
- Evidence-based AI explanations

## Constraints
- Current financial data must come from configured providers.
- Financial calculations must be deterministic.
- Simulations must be labelled hypothetical.
- No guaranteed-return claims.
